# Tic-Tac-Toe
A simple two-player console-based Tic-tac-toe game written in C++.

## Features
- Two-Player game.
- Board updates after every move.
- Win condition detection.
- Draw detection.

## Playing the game
### Steps
- Download the "main.cpp" file.
- Save it in a folder. (Example: Desktop/)
- Open the command prompt in the folder and run the following commands.

### Compile and Run
```bash
g++ main.cpp -o main
main
